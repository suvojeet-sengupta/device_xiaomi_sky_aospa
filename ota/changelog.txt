Changes
- Kernel: Suvkernel 2.0. The scheduler runs EEVDF with PELT and EAS instead of WALT, with the schedutil governor on both clusters
- Games get the touch game mode and a CPU boost while they are in front
- Settings > Display > Touch game mode (and a Quick Settings tile) sets touch game mode to Auto, Always on or Off
- Widevine can load its L1 library again, so DRM apps such as Hotstar can play in HD
- Transparent huge pages only for apps that ask for them, so games keep more memory before they get killed
- Stronger vibration with a quicker start
- The display power domain no longer leaves its supply locked after screen off, a likely cause of the garbled screen after wake
- The IR blaster clock no longer runs under-volted
- Network Signal Guru and other DIAG tools reach the modem on user builds

OTA updates
- Phones on 20261025 or newer update through Settings > System > System update. Older builds flash this one from recovery once
