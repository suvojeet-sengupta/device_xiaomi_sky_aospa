Changes
- Refresh rate: 60 Hz is now offered next to 90 Hz in Settings > Display > Refresh rate
- The Quick Settings media player no longer lags after pausing and resuming: the UI renders with OpenGL again
- Downloads no longer stall the phone: the mobile data memory pool stops failing allocations that made the system kill apps
- Better screen-off sleep with fewer wakeups (IPA interrupt and power domain fixes, lazy RCU)
- The touchscreen tells the display again when its firmware has loaded
- Kernel rebuilt with every module signed

OTA updates
- Phones on 20261025 or newer update through Settings > System > System update. Older builds flash this one from recovery once
